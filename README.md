# TableBooking

Сайт для бронирования столиков в ресторане

## Описание:

**TableBooking** - сайт для бронирования столиков в ресторане. Проект реализован на Django, интерфейс создан с помощью
Bootstrap. Поддерживает периодическую задачу через Celery и Celery Beat - перевод бронирований в статус "Завершено" при
окончании времени бронирования.

## Структура проекта

- `reservations` - столики, бронирования (CRUD бронирований), CBV (class-based views) для главной и страницы "О
  ресторане";
- `users` - кастомный пользователь, регистрация/вход/выход;
- `content` - модели для контента главной и страницы "О ресторане", управляется через админку;
- `config` - настройки проекта, celery-конфигурация.

## Функциональность проекта:

В рамках проекта реализован следующий функционал сайта:

1. Главная страница (`/`):

- описание ресторана (модель HomePage);
- перечень предоставляемых услуг (модель Services);
- контактная информация (модель Contacts);
- форма для обратной связи (модель Feedback).

2. Страница "О ресторане" (`/about/`):

- история ресторана (модель AboutPage);
- миссия и ценности (модели AboutPage, Values);
- команда (модель Staff).

Вышеуказанные страницы наполняются контентом через админку, для чего создано приложение 'content' и созданы
соответвующие модели, настроена админка. CBV (class-based views) для отображения страниц и HTML-шаблоны созданы в
приложении reservations.

3. Страница бронирования (`/reservations/check/`):

- форма для бронирования столика (форма ReservationForm - ввод времени бронирования и количества гостей);
- просмотр доступности столиков (ReservationCheckView);
- создание и подтверждение бронирования (ReservationCreateView, функция reservation_verification)

Функциональность бронирования реализована через приложение 'reservations'

- список бронирований (`/reservations/`)
- просмотр деталей бронирований (`/reservations/<id>/`)

4. Личный кабинет:

- регистрация и авторизация пользователей;
- просмотр истории бронирований (`/reservations/`для авторизованных пользователей) ;
- управление текущими бронированиями: *изменение* `/reservations/update/<id>/`, форма ReservationUpdateForm;
  *отмена* `/reservations/delete/<id>/` - перевод бронирования из статуса "Создано" или "Подтверждено" в статус "
  Отменено", полное удаление возможно через админку).

В приложении 'users' реализована регистрация, авторизация и выход пользователей. Модель пользователя User содержит поля
email, имя, телефон (необязательное). Авторизация осуществляется по email и паролю.

## Установка и настройка:

### Клонируйте репозиторий:

```
https://github.com/hristyaa/TableBooking.git
```

### Создайте виртуальное окружение и установите необходимые зависимости из `pyproject.toml`:

Выполните команду:

```
poetry install
```

Основные зависимости проекта:

- Django 4.2.2
- PostgreSQL (psycopg[binary])
- django-phonenumber-field[phonenumberslite]
- Pillow (работа с изображениями)
- Celery
- django-celery-beat
- Redis
- Coverage
- Eventlet (для запуска Celery на Windows)

### Настройка переменных окружения

Скопируйте файл `.env.example` и переименуйте его в `.env`
Откройте `.env` и заполните ваши данные.

### Применение миграций

```
python manage.py migrate
```

### Запуск Redis

```
redis-server
```

### Запуск локального сервера

```
python manage.py runserver
```

После запуска сервера приложение будет доступно по адресу: `http://127.0.0.1:8000/`

### Запуск Celery Worker (в отдельном терминале)

```
celery -A config worker -l info
```

Для Windows используется -P eventlet.

### Запуск Celery Beat (в отдельном терминале)

```
celery -A config beat -l info
```

### Запуск проект через Docker

- Сборка и запуск контейнеров:

```
docker compose up -d --build
```
- Применение миграций:
```
docker compose exec backend python manage.py migrate
```
- Загрузка данных:

```
docker compose exec backend python manage.py loaddata fixture.json
```

- Остановка контейнеров:

```
docker compose down
```

После запуска приложение будет доступно по адресу: `http://127.0.0.1:8080/`
