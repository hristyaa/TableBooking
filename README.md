# TableBooking

Сайт для бронирования столиков в ресторане

## Описание:

**TableBooking** - сайт для бронирования столиков в ресторане. Проект реализован на Django, интерфейс создан с помощью
Bootstrap. Поддерживает периодическую задачу через  Celery и Celery Beat - перевод бронирований в статус "Завершено" при окончании времени бронирования. 

## Функциональность проекта:
В рамках проектах реализован следующий функционал сайта:
1. Главная страница (`http://127.0.0.1:8000/`):
- описание ресторана (модель HomePage);
- перечень предоставляемых услуг (модель Services);
- контактная информация (модель Contacts);
- форма для обратной связи (модель Feedback).
2. Страница "О ресторане" (`http://127.0.0.1:8000/about/`):
- история ресторана (модель AboutPage);
- миссия и ценности (модели AboutPage, Values);
- команда (модель Staff).

Вышеуказанные страницы наполняются контентом через админку, для чего создано приложение 'content' и созданы соответвующие модели, настроена админка. Viewset's для отображения страниц и HTML-шаблоны созданы в приложении reservations.

3. Страница бронирования (`http://127.0.0.1:8000/reservations/check/`):
- форма для бронирования столика (форма ReservationForm - ввод времени бронирования и количества гостей);
- просмотр доступности столиков (ReservationCheckView);
- создание и подтверждение бронирования (ReservationCreateView, функция reservation_verification)

Страница бронирования реализованы через приложение 'reservations'

4. Личный кабинет:
- регистрация и авторизация пользователей;
- просмотр истории бронирований (для авторизованных пользователей ;
- управление текущими бронированиями (изменение, отмена).

В приложении 'users' реализована регистрация, авторизация и выход пользователей. Модель пользователя User содержит поля email, имя, телефон (необязательное). Авторизация осуществляется по email и password.
